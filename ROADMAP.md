# Roadmap

> ICO Standards Framework development roadmap. All dates are targets and subject to adjustment based on community feedback.

## 2026: Foundation & v2.0 Public Review

### Q2 2026 (Apr–Jun) ✅ Completed

- [x] **White Paper v1.0–v1.3** — Iterative development and public release
- [x] **DPP-CQ v0.5 Draft** — First draft of DPP-CQ technical specification
- [x] **JSON Schema v1.0 & Example** — DPP-CQ JSON Schema + Longjing tea example credential
- [x] **GitHub Community Launch** — Open source repository & community channels
- [x] **First Public Review (v1.3)** — Comment period: Jul 6 – Aug 20, 2026

### Q3 2026 (Jul–Sep) ✅ In Progress

- [x] **White Paper v2.0** — Major revision: GS1 Digital Link, three-tier carriers, dual credential formats, sustainability, AI transparency, data lifecycle governance
- [x] **JSON Schema v2.0.0-draft** — All v2.0 modules added (sustainability, carrierTier, gs1DigitalLink, dataLifecycle, aiDisclosure)
- [x] **v2.0 Example Credential** — Full interoperability configuration example (Longjing tea)
- [x] **Normative Annexes** — 5 normative documents created:
  - GS1 Digital Link Mapping
  - Carrier Specification (L1/L2/L3)
  - Credential Formats (BBS+ / SD-JWT VC)
  - Conformity Declarations
  - PIA Summary
- [x] **Governance Charter v0.5** — Multi-stakeholder governance framework
- [x] **Standard Numbering** — Unified to ICO Std 2001 (previously ICO-TS-001)
- [x] **dppcq.org Standard Portal** — Full website deployed
- [x] **verify.icoun.org** — Product & institution verification platform
- [ ] **Second Public Review (v2.0)** — Comment period: Sep 1 – Oct 15, 2026 *(in progress)*
- [ ] **v2.0 PDF Generation** — White paper + annexes compiled as PDF *(after review)*

### Q4 2026 (Oct–Dec)

- [ ] **DPP-CQ v2.0 Final** — First stable release after public review
- [ ] **v2.0 PDF Publication** — Official PDF documents
- [ ] **Reference Implementation** — Open-source reference implementation of DPP-CQ
- [ ] **SDK v0.1 (Python / JS)** — First developer SDKs
- [ ] **Root Resolver Network (Prototype)** — Initial prototype of root DID resolution infrastructure
- [ ] **Pilot Programs Launch** — First batch of pilot products (tea, ceramics, haute couture)
- [ ] **Global Digital Credibility Governance Summit** — First major community event

## 2028+: Global Mutual Recognition & Maturity

### Targets

- **10+ standards** covering multiple product categories
- **20+ regional nodes** across continents
- **1,000+ institutional members**
- **100,000+ certified products** globally
- **Formal mutual recognition** with major international standards bodies
- **UNESCO / WIPO formal partnership** for cultural heritage digital protection
