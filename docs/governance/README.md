## Governance Charter v0.5

The Governance Charter establishes the institutional framework for DPP-CQ standard development and maintenance:

- **Membership categories**: Full Members, Associate Members, Observers
- **Decision-making**: ICO Standards Council with consensus-based voting
- **Working Groups**: Technical WG, Governance & Compliance WG, Interoperability WG, Use Cases & Pilots WG
- **IPR policy**: Royalty-free licensing for standard implementation
- **Dispute resolution**: Escalation from WG → Council → external arbitration

### Public Comment

The Charter is currently in Working Draft status and open for public comment through October 15, 2026. Submit feedback via [GitHub Issues](https://github.com/ICO-cloud/dpp-cq-standard/issues) or email info@icoun.org.
