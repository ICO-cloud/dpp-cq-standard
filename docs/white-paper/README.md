### v2.0 Enhancements

The v2.0 white paper incorporates all enhancements from the second public review period:

- GS1 Digital Link interoperability
- Three-tier carrier specification (L1/L2/L3)
- Dual credential formats (BBS+ and SD-JWT VC)
- Chinese cryptography optional module (SM2/SM3/SM4)
- Sustainability module aligned with ISO 14067
- AI transparency disclosure (EU AI Act Art.50)
- Governance Charter v0.5 reference
